# ICEBREAK (web)

Compiled web version of ICEBREAK for browsers without the Android app (iPhone with Safari).
Cover page at the root (Android downloads, link to the web app in app/). Open the web app in Safari and use "Share → Add to Home Screen" so it works as an app and keeps its data.

This repository only contains the built files. Source code is not published here.
